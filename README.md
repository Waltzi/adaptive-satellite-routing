# Adaptive Satellite Routing Simulator 🚀

## Overview
This project simulates a dynamic satellite-ground station network with adaptive routing to optimize data transfer.

## Features
- Real-time orbital mechanics using TLE data
- Adaptive routing for dynamic connectivity
- Fault-tolerant network simulation

git clone https://github.com/Waltzi/adaptive-satellite-routing.git
